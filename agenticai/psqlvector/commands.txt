=================================================================
POSTGRESQL FULL-TEXT SEARCH - COMPLETE COMMAND REFERENCE
=================================================================

INITIAL SETUP:
cd ~/Downloads/psqlvector

ONE-COMMAND COMPLETE SETUP:
./setup.sh

QUICK TEST (after setup):
./quick_test.sh

FULL TEST SUITE (all 20 tests):
./test.sh

=================================================================
STEP-BY-STEP MANUAL SETUP (if not using setup.sh)
=================================================================

1. CREATE DATABASE:
createdb -U postgres psqlvector_db

2. ENABLE EXTENSIONS:
psql -U postgres -d psqlvector_db -f 01_extensions.sql

3. CREATE TYPES:
psql -U postgres -d psqlvector_db -f 02_types.sql

4. CREATE TABLES:
psql -U postgres -d psqlvector_db -f 03_tables.sql

5. CREATE INDEXES:
psql -U postgres -d psqlvector_db -f 04_indexes.sql

6. CREATE TRIGGERS:
psql -U postgres -d psqlvector_db -f 05_triggers.sql

7. CREATE SEARCH FUNCTION:
psql -U postgres -d psqlvector_db -f 06_search_function.sql

8. INSERT SAMPLE DATA:
psql -U postgres -d psqlvector_db -f 07_sample_data.sql

9. RUN TESTS:
psql -U postgres -d psqlvector_db -f 08_test_queries.sql

=================================================================
CONNECTING TO DATABASE
=================================================================

Interactive shell:
psql -U postgres -h localhost -d psqlvector_db

Single command:
psql -U postgres -h localhost -d psqlvector_db -c "COMMAND"

=================================================================
COMMON TEST COMMANDS
=================================================================

1. BASIC TSVECTOR:
psql -U postgres -d psqlvector_db -c "SELECT to_tsvector('english', 'The quick brown foxes');"

2. BASIC TSQUERY:
psql -U postgres -d psqlvector_db -c "SELECT to_tsquery('english', 'postgresql & database');"

3. SIMPLE KEYWORD SEARCH:
psql -U postgres -d psqlvector_db -c "SELECT id, title FROM articles WHERE search_vector @@ to_tsquery('english', 'postgresql') LIMIT 10;"

4. RANKED SEARCH:
psql -U postgres -d psqlvector_db -c "SELECT id, title, ts_rank(search_vector, to_tsquery('english', 'postgresql')) as rank FROM articles WHERE search_vector @@ to_tsquery('english', 'postgresql') ORDER BY rank DESC LIMIT 10;"

5. SEARCH WITH HIGHLIGHTS:
psql -U postgres -d psqlvector_db -c "SELECT id, title, ts_headline('english', content, to_tsquery('english', 'article'), 'StartSel=<mark>, StopSel=</mark>, MaxWords=30') as snippet FROM articles WHERE search_vector @@ to_tsquery('english', 'article') LIMIT 5;"

6. ADVANCED SEARCH FUNCTION (basic):
psql -U postgres -d psqlvector_db -c "SELECT * FROM search_articles('postgresql', page_size => 10);"

7. ADVANCED SEARCH (with filters):
psql -U postgres -d psqlvector_db -c "SELECT * FROM search_articles('article', tag_filter => ARRAY['postgresql', 'database'], page_size => 10);"

8. SEARCH WITH DATE RANGE:
psql -U postgres -d psqlvector_db -c "SELECT * FROM search_articles('article', min_date => CURRENT_TIMESTAMP - INTERVAL '1 year', page_size => 10);"

9. PAGINATION TEST:
psql -U postgres -d psqlvector_db -c "SELECT id, title FROM search_articles('article', page_size => 5, page_number => 1);"

10. STATISTICS:
psql -U postgres -d psqlvector_db -c "SELECT COUNT(*) as total_articles, COUNT(DISTINCT author_id) as authors FROM articles;"

=================================================================
OR/AND/NOT QUERIES
=================================================================

OR Search (postgresql OR elasticsearch):
psql -U postgres -d psqlvector_db -c "SELECT COUNT(*) FROM articles WHERE search_vector @@ to_tsquery('english', 'postgresql | elasticsearch');"

AND Search (postgresql AND database):
psql -U postgres -d psqlvector_db -c "SELECT COUNT(*) FROM articles WHERE search_vector @@ to_tsquery('english', 'postgresql & database');"

NOT Search (postgresql NOT elasticsearch):
psql -U postgres -d psqlvector_db -c "SELECT COUNT(*) FROM articles WHERE search_vector @@ to_tsquery('english', 'postgresql & !elasticsearch');"

=================================================================
PERFORMANCE ANALYSIS
=================================================================

Query plan (basic):
psql -U postgres -d psqlvector_db -c "EXPLAIN ANALYZE SELECT * FROM articles WHERE search_vector @@ to_tsquery('english', 'postgresql') LIMIT 10;"

Query plan (complex):
psql -U postgres -d psqlvector_db -c "EXPLAIN ANALYZE SELECT * FROM search_articles('postgresql', tag_filter => ARRAY['database']);"

=================================================================
CLEANUP
=================================================================

Drop database:
psql -U postgres -c "DROP DATABASE psqlvector_db;"

DIAGNOSTIC COMMANDS

List tables:

List indexes:
