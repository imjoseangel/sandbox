TRY THESE COMMANDS:

1. Search for articles:
   psql -U postgres -d psqlvector_db -c \
   "SELECT id, title FROM articles WHERE search_vector @@ to_tsquery('english', 'article') LIMIT 5;"

2. Search with ranking:
   psql -U postgres -d psqlvector_db -c \
   "SELECT id, title, ts_rank(search_vector, to_tsquery('english', 'article')) as rank FROM articles WHERE search_vector @@ to_tsquery('english', 'article') ORDER BY rank DESC LIMIT 5;"

3. Search with highlights:
   psql -U postgres -d psqlvector_db -c \
   "SELECT id, ts_headline('english', content, to_tsquery('english', 'article'), 'StartSel=<mark>, StopSel=</mark>, MaxWords=15, MinWords=1') FROM articles WHERE search_vector @@ to_tsquery('english', 'article') LIMIT 3;"

4. AND search:
   psql -U postgres -d psqlvector_db -c \
   "SELECT COUNT(*) FROM articles WHERE search_vector @@ to_tsquery('english', 'article & content');"

5. OR search:
   psql -U postgres -d psqlvector_db -c \
   "SELECT COUNT(*) FROM articles WHERE search_vector @@ to_tsquery('english', 'article | title');"
